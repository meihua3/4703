# FairCity Check — Digital Fairness Audit Portal

## Description

This is a **design fiction website** that imagines a future government portal in 2045. The website explores what happens when digital fairness becomes mandatory for all public systems.

**Key theme:** Slowing down systems to ensure multilingual fairness.

The project consists of two HTML pages:
- **faircity-check.html** — Main portal with audit examples and stakeholder perspectives
- **rationale.html** — Academic explanation connecting this fiction to Assignment 2

## Installation

**No installation required.** This project uses only HTML and CSS.

### Requirements
- A web browser (Chrome, Firefox, Safari, Edge, etc.)
- No special software needed
- No dependencies or frameworks

## How to Run

1. Download or clone this folder to your computer
2. Open `faircity-check.html` in any web browser
3. Click "About" in the navigation to view `rationale.html`

That's it! The website runs locally in your browser.
